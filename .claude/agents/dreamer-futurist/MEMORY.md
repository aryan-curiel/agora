# Memory — The Futurist

*Last updated: 2026-05-12*

## Structural Patterns That Hold Across Sessions

**The loop-removal failure mode.** Any proposal that removes the primary user from the decision process contradicts the core value proposition (self-trust development). Autonomy proposals that "run continuously" or "decide for you" will be Skeptic-flagged and should be reframed as ambient support, not replacement.

**Marketplace proposals require a named supply side.** Community-contributed specialists, vertical specialist packs, and idea genome markets all share the same structural weakness: the supply side has no clear source. Flag this before proposing; either solve it or scope to a curated-by-team model first.

**Organizational memory / decision graph is a recurring trap.** Proposed in both sessions under different framings (Idea Graph, Organizational Memory, Decision Fingerprint, Organizational Epistemics). Skeptic-flags consistently on retrieval discipline as the unsolved problem. This is a structural pattern, not an implementation detail. Do not re-propose without a concrete answer to: "How does the system know which past decision is relevant right now?"

**API-first entry is the highest-confidence early path.** Single-endpoint, no-auth, curl-friendly distribution consistently survives skeptic scrutiny. The question is not whether to go API-first but what travels after the curl (shareable artifact, replay link, email capture).

## Moonshot Horizons That Are Directionally Sound

**Ambient reasoning embedded in developer workflow** (VS Code/Cursor extension, 60-second micro-debates at architectural decision points) — category-defining, not incremental. Survives because it keeps the user in the loop.

**Post-human strategy consultant category** — 20-specialist debates cheaper than a consulting hour; displaces junior consulting for SMBs. Credible because price asymmetry is real and the output format maps to existing consulting deliverables.

**Regulatory compliance proof-of-deliberation** — session logs as deliberation artifacts. Directionally interesting but legally unfounded as proposed; regulators require human accountability chains. Valid as a future horizon, not a near-term claim.

**The Dissent Layer** — most novel moonshot from Session 2. No Skeptic-flag recorded. Worth developing further.

## Viral Distribution Patterns

**What travels from a curl response:** a 200-word "Debate Summary Card" with a public replay link. Concrete artifact, zero friction, captures email before exit via exit-intent on replay pages. This solves the "what travels?" problem.

**Session-to-PRD pipeline** identified as strongest growth direction — output format that maps to existing workflow artifacts drives retention without requiring behavior change.

**Prefilled demo with real decision archetypes** outperforms blank-slate onboarding. Three prefilled ideas from common founder decision types reduces activation drop-off.

## Skeptic Interaction Patterns

The Skeptic's most reliable challenge categories:
1. Supply side undefined (marketplaces)
2. Retrieval discipline unsolved (knowledge graphs)
3. Legal/regulatory claims without accountability chain
4. Retention hooks that require retention to fire (chicken-and-egg)
5. Loop removal (autonomous agents)

Pre-empt these by naming the specific weakness in the proposal before presenting it, then offering a constrained version that sidesteps it.

## Differentiation: Futurist vs. Other Dreamers

- **Futurist owns:** category-level shifts, 3-5 year horizon moonshots, infrastructure-layer thinking, API primitives, B2B2D (business-to-developer-to-decision-maker) positioning.
- **Connector owns:** cross-domain analogies, unexpected partnership angles.
- **Builder owns:** implementation pathways, technical feasibility gates.
- **User Advocate owns:** friction points, onboarding, founder emotional journey.

In rounds with multiple dreamers, lead on moonshots and API primitives; defer implementation specifics to Builder and onboarding specifics to User Advocate.
