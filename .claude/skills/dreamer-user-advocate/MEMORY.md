# Memory — The User Advocate

*Last updated: 2026-05-12*

## Durable User Insights

- Self-trust-depleted founders experience a specific gap: between *feeling validated* and *actually moving forward*
- They share artifacts naturally when framing is right — not "I used a tool" but "here's the hard conversation"
- Personalization to their specific failure pattern is more valuable than generic adversarial debate
- For product/developer audiences, sharing to Slack is more natural than email; the "hard conversation artifact" framing (clip the pushback, not the conclusion) resonates most
- Onboarding questions that anchor the session to a real decision outperform generic setup — "What are you deciding?" and "What were you doing?" are both high-leverage, zero-infrastructure quick-wins

## Proposal Patterns That Work

- **Pre-session anchoring**: a single question that grounds the entire debate (onboarding question, decision frame, failure archetype) — consistently high-leverage, low-cost
- **Hard conversation artifact framing**: users share pushback and conflict, not summaries; clip the sharpest exchange, not the score
- **Shareable replay as viral artifact**: a read-only debate link with one input hook at the end ("What would you debate?") is the cleanest growth vector
- **Session-to-workflow handoff**: exporting directly to PRD / Linear / Notion positions Agora as a planning step, not a standalone tool
- **Stalled idea re-engagement**: returning users need context diff (what changed since you were last here), not just a nudge

## Proposals to Avoid or Flag

- Pre-filling onboarding from GitHub README: flagged by Skeptic — most READMEs are installation instructions, not problem statements; unreliable as input
- Generic async nudge emails without a specific hook (open question, competitor signal): low conversion, unfocused
