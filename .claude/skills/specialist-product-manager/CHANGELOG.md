# Changelog — specialist-product-manager

## [1.1.0] — 2026-05-08

### Added
- Memory system: reads `[YOUR MEMORY]` from context at the start of each debate contribution to apply accumulated patterns about PoC scope creep and vanity metric disguises.
- Memory update mode: when invoked with `MODE: memory-update` by agora-run-debate after session completion, generates an updated `MEMORY.md` capturing scope anti-patterns, roadmap failure modes, and risky assumption types by idea category.
