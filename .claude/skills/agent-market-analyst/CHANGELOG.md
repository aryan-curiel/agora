# Changelog — agent-market-analyst

## [1.1.0] — 2026-05-08

### Added
- Memory system: reads `[YOUR MEMORY]` from context at the start of each debate contribution to apply accumulated patterns about ICP mistakes and distribution channel fit by audience type.
- Memory update mode: when invoked with `MODE: memory-update` by run-debate after session completion, generates an updated `MEMORY.md` capturing recurring ICP errors, overlooked competitors, and market size calibration patterns.

## [1.0.0] — 2026-05-08

### Added
- Initial version: Market Analyst that defines a specific ICP, names 2-3 direct competitors, estimates market size, and proposes the single most concrete first distribution channel.
