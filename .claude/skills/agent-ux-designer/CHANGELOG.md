# Changelog — agent-ux-designer

## [1.1.0] — 2026-05-08

### Added
- Memory system: reads `[YOUR MEMORY]` from context at the start of each debate contribution to apply accumulated patterns about distracting features and proven scope cuts.
- Memory update mode: when invoked with `MODE: memory-update` by run-debate after session completion, generates an updated `MEMORY.md` capturing recurring unnecessary feature types, user journey patterns, and moment-of-value findings.
